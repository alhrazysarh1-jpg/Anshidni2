# مشروع انشدني — Ask me

موقع سياحي يعمل بالكامل داخل المتصفح (HTML + CSS + JavaScript) بدون سيرفر.

## التشغيل
- افتحي `index.html` عبر خادم محلي (مثل Live Server في VS Code)، أو ارفعي المجلد على **GitHub Pages**:
  1. أنشئي مستودعًا جديدًا وارفعي كل الملفات كما هي (يكون `index.html` في الجذر).
  2. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `root` ← Save.
  3. بعد دقيقة يظهر رابط الموقع.

## التحديثات الأخيرة
1. **الشعار:** نسخة شفافة بإطار أبيض (`logo-anshidni-transparent.png` و `anshidni-icon-transparent.png`) في الشريط العلوي وشاشة التحميل والأيقونة.
2. **الصور:** كل صور المدن والأماكن صور حقيقية من ويكيميديا كومنز بترخيص حر، محفوظة مع ملفات الموقع، والمصادر في زر «مصادر الصور» أسفل الموقع.
   - لتغيير صورة مكان: عدّلي `placeImages` في `script.js`.
   - بعض الأماكن ليس لها صورة حرة، فاستُخدمت لها صورة من نفس النوع (حديقة/مطعم) كصورة تعبيرية.
3. **الألوان:** ألوان أفتح مأخوذة من الشعار (تركواز، كحلي، أصفر، بنفسجي، وردي) في أعلى ملف `style.css` داخل `:root`.
4. **صفحة حسابي:** بشكل يشبه تويتر (غلاف، صورة شخصية، نبذة، تبويبات، حركات)، مع اختيار عام/خاص وزر «كيف يرى الآخرون حسابي؟».
5. **صفحة آراء الناس:** منشورات بالصور والتقييم، إعجاب، ردود، تصفية حسب النوع والمدينة.
6. **الإيميل:** زر `anshedni.team@gmail.com` يفتح تطبيق البريد، وينسخ الإيميل تلقائيًا، وفيه رابط بديل عبر Gmail.

## الحسابات والخصوصية
- إنشاء حساب وتسجيل دخول بالبريد وكلمة المرور (كلمة المرور تُحفظ مشفّرة SHA-256).
- لكل حساب بياناته الخاصة: الجدول، التعليقات، الذكريات.
- الحساب **العام**: منشوراته وذكرياته العامة تظهر للجميع.
- الحساب **الخاص**: محتواه يظهر فقط للمتابعين الذين يقبلهم صاحب الحساب (طلبات المتابعة تظهر في «حسابي»).
- لتجربة الخصوصية: أنشئ حسابين على نفس المتصفح، اجعل أحدهما خاصًا، وادخل بالآخر وافتح ملفه.

## الخريطة
خريطة أساسية للمنطقة مضمّنة في `basemap.js` (Natural Earth) تعمل بدون إنترنت، وتظهر فوقها خريطة OpenStreetMap التفصيلية عند توفر الإنترنت.

## ملاحظة مهمة
البيانات تُحفظ في `localStorage` داخل المتصفح، لذلك الحسابات والمنشورات مشتركة بين من يستخدمون نفس المتصفح فقط.
لجعلها مشتركة بين أجهزة مختلفة يلزم ربط قاعدة بيانات (مثل Supabase) — وهذه مرحلة لاحقة.
